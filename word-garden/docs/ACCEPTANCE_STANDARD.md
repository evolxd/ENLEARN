# 词汇花园 · 验收标准

每一批新词在推送前必须全部通过。A 类由脚本 `scripts/validate_lessons.py` 自动检查，B 类人工抽查。

## A. 自动检查（脚本，任何一条失败即不得推送）
| 编号 | 检查 |
|---|---|
| A1 | 每节恰好 10 词；每课 2 节；id 连续且不与已有 id 重复 |
| A2 | 单词（不分大小写）在整个页面内不重复 |
| A3 | 所有必填字段非空（G4 的 10 个字段） |
| A4 | chunks 与 sounds 音节数相等；chunks 中恰有一个或多个大写音节且去掉 `·` 后拼回单词（多音节词） |
| A5 | 例句 ≤ 12 词，且包含该词（允许常见变形：加 s/es/ed/ing，去 e 加 ing/ed，y 变 i）|
| A6 | 英文释义 ≤ 15 词，且不包含被释词本身 |
| A7 | 每词有 `word-<id>.mp3` 与 `def-<id>.mp3`，每节有 `group-<n>.mp3`，文件非空 |
| A8 | 页面记录的节时长与 mp3 实际时长相差 ≤ 0.2 秒；每词 4 个时间点，递增且不重叠 |
| A9 | 释义音频的语速（词/秒）落在已有音频范围内（0.6 倍到 1.2 倍中位数之间） |
| A10 | 页面能加载，控制台无错误；节数统计与实际一致 |

## B. 人工抽查（每批至少抽 10 词）
| 编号 | 检查 |
|---|---|
| B1 | 中文意思、释义、例句三者意思一致，且是该词最常用义 |
| B2 | 音标与词典一致；目标元音读法与 tip 一致 |
| B3 | tip 与 memory 不含错误词源或错误规则 |
| B4 | 听 3 条音频：发音清楚、语速一致、没有截断或杂音 |
| B5 | 例句适合 10–11 岁孩子，无不当内容 |

## C. 范围声明检查
| 编号 | 检查 |
|---|---|
| C1 | 分组名带「（拓展）」，README 与 GENERATION_STANDARD 写明「推测编排，非教材原文」 |
| C2 | 推送说明里写清：核对了什么、没核对什么 |
