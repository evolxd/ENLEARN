# 词汇花园 · 生成标准

适用范围：第 11 课及以后新增的拼写课。第 7–10 课和基础 5 组沿用原有格式，不改动。

## 1. 来源与标注（G1）
- 素里（Surrey, BC）5 年级没有公开的统一词表。老师用的教材（课内活动名 Say and Listen / Think and Sort / Spelling and Meaning，与 Steck-Vaughn *Spelling: Linking Words to Meaning* Level 5 一致）的逐课词表无法在网上核对。
- 已知事实：第 7、8 课是长音 /iː/，第 9、10 课是短音 /ɪ/。据此推测教材按 短a、长a、短e、长e、短i 之后顺序编排：长i、短o、长o、短u、长u……每个元音两课，每课 20 词。
- 因此第 11 课起的词表是**按这个规律推测编排的拓展词表**，不是教材原文。页面分组名统一带「（拓展）」，README 与本文件都如实说明。拿到真实教材词表后，直接替换即可。

## 2. 结构（G2）
- 每「节」（一次听写）固定 10 词；每课 2 节，共 20 词。
- 同一课的 20 词围绕同一个元音和同一类拼写规律；每个词标注 `pattern`（例如 i_e、igh、y、o、a）。

## 3. 选词（G3）
1. 五年级常见词，避免过冷的词；不含专有名词、缩写、复合短语。
2. 不与页面已有任何单词重复（不分大小写）。
3. 读音必须真的属于本课的目标元音（例外：同一课里作为「对比」的词，要在 tip 里写明）。
4. 学生在加拿大，单词、例句、释义一律用加拿大拼法（colour、honour、favourite、neighbour、centre），tip 里可对照美式拼法。
5. 单词本身是日常词，孩子能在例句里理解。

## 4. 每个词的字段（G4）
| 字段 | 要求 |
|---|---|
| id | 连续整数，课内不跳号 |
| en / zh | 英文原形；中文给最常用的 1–2 个意思，用「；」分隔 |
| ex / cn | 英文例句 ≤ 12 个词，必须出现该词（可变形），语境贴近学校生活；cn 是自然的中文翻译 |
| definition | 英文释义 ≤ 15 个词，不含被释词本身，用五年级能懂的词；多义词用「; also …」补第二个常用义 |
| chunks | 音节用 `·` 分隔，重读音节大写，例如 `de·CIDE` |
| ipa | 美式音标，带重音符号 |
| sounds | 与 chunks 音节数一致，用 `·` 分隔，对应每个音节的音标 |
| tip | 一句中文读音提示：重音在哪、目标元音怎么读、易错点 |
| memory | 一句中文记忆提示：拆词、同族词或联想；不编造词源 |
| pattern | 本词体现的拼写规律 |

## 5. 音频（G5）
- 声音：英文 `en-US-AndrewNeural`，中文 `zh-CN-XiaoxiaoNeural`（edge-tts），与已有音频同一配音。
- 每词 4 段：中文意思、英文单词、英文例句、中文例句；段间静音 2 ÷ 0.87 秒。
- 单独朗读的英文单词，TTS 在默认语速下会被读得过短过快（实测 flight 只有约 0.16 秒），所以这一段用 `rate=-30%` 合成；句子和中文保持默认语速。
- 所有新音频整体做 `atempo=0.87`，与第 10 课及之前已放慢的音频语速一致。
- 每节一个完整音频 `group-<n>.mp3`（10 词，末尾留一个间隔）；每词一个 `word-<id>.mp3` 和一个释义音频 `def-<id>.mp3`。
- 单声道、22050 Hz、32 kbps；页面里记录的时间点必须由实际样本长度计算，不得手填。

## 6. 页面接入（G6）
- 数据块 `lessonNEntries`，`g` 为新分组序号，`groups.push("第N课 Lesson N")`。
- 在 `DICTATION_AUDIO.sessions` 末尾追加新节；`EN_DEFS` 补全英文释义；页面里的组数统计同步更新。
- 不修改任何已有词条和已有音频。

## 7. 流程（G7）
生成 → 跑 `scripts/validate_lessons.py` → 浏览器抽查 → 对照《验收标准》逐条通过 → 才能提交推送。
