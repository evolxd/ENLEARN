# 五年级词汇花园 · Word Garden

ENLEARN 的静态词汇听写模块。打开 `index.html`，或访问 GitHub Pages：`/ENLEARN/word-garden/`。

内容：31组听写音频、310个单词音频（含第9、10课 /ɪ/ 拼写词，以及第11–18课拓展词）、拼读与记忆提示、家长答案锁、循环播放及打印功能。音频均为相对路径，无需登录。

家长密码与锁定状态保存在当前浏览器，不跨域或跨设备同步；首次访问需重新设置。练习锁不用于保护敏感数据。


## 关于第11课以后的词表
素里5年级没有公开的统一词表，老师用的教材逐课词表也查不到。第7、8课是长音 /iː/，第9、10课是短音 /ɪ/，据此推测教材每个元音讲两课（每课20词）。第11–18课按这个规律编排（长音 /aɪ/、短音 /ɑː/、长音 /oʊ/、短音 /ʌ/，各两课），分组名带「（拓展）」，**不是教材原文**。生成与验收标准见 `docs/GENERATION_STANDARD.md`、`docs/ACCEPTANCE_STANDARD.md`，自动检查脚本是 `scripts/validate_lessons.py`。
