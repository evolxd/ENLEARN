# Words 061–090（词汇 061–090）

Part: Part III — PTE High Frequency Lexicon
Status: Draft (Batch 3 of the planned 300–500 word target; batch size 30 words, per `README.md`)
Accent model: General American (GA), consistent with Parts II and IV

**Sourcing note**: same as Batches 1–2 — IPA and stress are standard, well-established dictionary pronunciations; this session's direct Cambridge/Oxford fetch attempts returned 403, so each entry should be individually cross-checked before being marked Done. "AI Recognition Notes" fields are `[Hypothesis]`-tagged reasoned extensions of Parts I and IV, not observed word-specific AI behavior data.

**Batch-specific note — the "-tion" suffix stress rule**: this batch is unusually rich in "-tion" nouns (*solution, situation, condition, communication, innovation, population, generation, education*). Part II Ch.4 already established that suffixes like *-tion*, *-ic*, and *-ity* reliably pull primary stress onto the syllable immediately before them. Rather than repeating that mechanism in each entry below, each "-tion" word's Common Mistakes/Chinese Learner Errors fields refer back to this note as "the -tion rule." The same batch also includes one "-ic" word (*economic*) applying the parallel rule, and a stress-shift pair (*economy*/*economic*) that mirrors Part II Ch.4's *photograph*/*photography*/*photographic* example directly.

Each entry follows `book/_TEMPLATE_LEXICON_ENTRY.md`. Chinese Learner Errors cross-reference Part IV's numbered mistakes where applicable.
