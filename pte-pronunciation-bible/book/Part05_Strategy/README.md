# Part V — Question Strategy

Status: Draft complete (all 10 chapters written — see `ROADMAP.md` Stage 4)

Applies the AI scoring model (Part I) and pronunciation foundations
(Part II) to each PTE Academic question type. Every strategy claimed here
must trace back to a stated scoring mechanism — no "trick" without an
explained reason, per `STYLE_GUIDE.md` §3.

Chapters 1–5 (speaking items) and Ch.10 (Listening) are this book's core
focus and connect directly to Parts I, II, and IV. Chapters 6, 8, 9
(Summarize Written Text, Essay, Reading) are writing/reading items with
no pronunciation component; they are included for completeness per the
original book structure but are intentionally lighter-touch, and each
says so in its own scope note. **Ch.7 (Write Email) is PTE Core–only**
— confirmed `[Practice]` across independent sources (see the chapter's
own References) that Write Email replaces Write Essay specifically in
PTE Core, while PTE Academic retains Write Essay (Ch.8). Ch.7 is kept
as supplementary material for readers also preparing for PTE Core, but
it is not part of this book's core PTE Academic curriculum — PTE
Academic test-takers should treat Ch.8, not Ch.7, as their writing-task
chapter. All format/timing figures across this Part are secondary-sourced
(the primary Pearson test-format pages returned 403 on direct fetch this
session, consistent with Part I's sourcing note) and need re-verification
before any chapter moves from Draft to Done.
