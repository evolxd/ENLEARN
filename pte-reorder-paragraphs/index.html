每题核心是「定序核心」三步：定首句 → 锁相邻对 → 定尾句，顺序随之唯一确定。这套推法能迁移到新题；「正确顺序」码是背熟后的快速提取。共 41 题。

三步定序 ① 首句：无代词回指、无 However/For this reason/They/These 类连接词、能引出话题的那句。② 锁相邻对：代词、this·these·such＋名词 都要往前找先行词；连接词接上一句；词汇复现（a few ↔ far more）把两句钉死并定方向。③ 尾句：结果句 / 评价句 / 无后续指代。截图里的编号只是乱序展示的句号，不是答案。
解题总纲PTE 排序题：一次全做对的方法

一句话：段落是一条逻辑链——定首句 → 一环扣一环锁下去 → 定尾句。顺序是推出来的，不是"读起来顺"猜出来的。失分几乎都在第 1、2 位；中间和结尾往往自动成立。

一、找首句：排除法（谁都不依赖前文，谁就是首句）

  1. 有代词、却无先行词 → 出局：it / they / them / he / she / his / this / that / these / those / such
  2. this·these·such·that ＋ 名词（this effort / this number / these times / such things）→ 是回指，出局
  3. 承接性连接词开头 → 出局：However / But / Therefore / For this reason / As a result / Also / Instead / In addition / Furthermore / On the other hand / Meanwhile　（注意：Because of X, … / Although … / When … 若 X 只是背景事实、不指向前一句，则可以作首句——别误杀）
  4. "the ＋ 名词"指向还没登场的东西（The company / The nerves / The movement；也包括普通名词 the shell / the fruit / the bank）→ 需先行词，出局。定冠词 the 在普通名词前也是回指信号，最容易被漏看。
  5. 专有名词的简称 / 第二次提及 → 全称、首次提及的那句排在前

剩下的那句（通常最概括、信息最"空"，只是抛出话题或背景）＝首句。若剩 ≥2 句都"能开头"，选说得最泛、零背景也能懂的那句；带机制 / 数据 / 举例 / 更宽泛重述的句子都排在后面。

⚠ 首句不一定"读起来最重要"。像目标句 / 评价句（"A healthy school setting gives all students the best chance…"）也能作首句——只要后面有句子用 this 回指它。

⚠ 最常见的陷阱：一句光秃秃的一般陈述（无代词、无连接词）读着像主题句，实际只是把另一句用更笼统的话重述一遍。判断法：如果句 X ≈ 句 Y 的"放大版"（X 说"人们要晋升机会才肯努力"，Y 说"想要更多责任的员工待在枯燥岗位会不满"），则 Y 在前、X 紧随其后，X 不是首句。

二、锁相邻对：定完首句就"机械追踪"，别再凭语感

每一步只问一个问题：剩下的句子里，哪一句往回勾住了我刚放下的这句？勾子只有四种：

  • 代词回指：They / It / This / These / Such → 往前找它指代的名词（名词必须在前）
  • this·these·such ＋ 名词 回指：this reason（前句给了理由）、this fruit（前句提了果实）、these species（前句提了两个物种）
  • 词汇复现 / 同义替换：a few ↔ far more than a few；ID ↔ your ID；the mission ↔ they
  • 逻辑连接词：For this reason / As a result（前句是因）、However / But（前句是对立面）、For example（前句是总述）、One of… / Another…（前句提了"多种/已给一个"）、also / In addition / even（前句已给过一条同类）

方向也被勾子锁死：名词在前、代词在后；因在前、果在后；总述在前、举例在后；说法在前、反驳在后；一般论断在前、解释它的句子在后；概括在前、结论在后。

⚠ 推理连接词的铁律：Therefore / Thus / So / Hence / Consequently / As a result / For this reason ＝「由前面所有内容推出」。它的前提必须先出现，它不接受在它之后再补论据 / 补概括。
所以只要一句以 In general / Overall / On the whole（概括）出现、另一句以 Therefore / Thus（下结论）出现，顺序必然是概括句 → 结论句，且结论句几乎一定收尾。
验证法：把结论句排到概括句前面读一遍——会读成"已经下完结论，又退回去补一条概括"，别扭 → 说明排反了。

三、定尾句：往回勾、但没有句子勾它

  • 结果 / 结论：ended up / in the end / finally / the result is / 以数字收尾（"…removing 45 rattlesnakes" / "netted more than 650,000 pounds"）
  • 评价 / 拔高：The point is… / we start to arrive at… / contributes to the perpetuation of…
  • 带 Therefore / Thus 的最终结论——永远是最后一句。若有 In general / Overall 的概括句，它排在 Therefore 前一位：结尾常是「In general …（概括）→ Therefore …（下结论）」两连。

⚠ 定义句（"Withdrawing money means…" / "X means…"）直觉像首句，实际常被放在相关内容之后。

五、六种题型套路（记住结构，秒排）

  1. 研究 / 实验型：研究目的 → 方法(分组) → 起初结果 → 后来结果 / 结论　(Q29 · Q19)
  2. 现象-原因-后果-对策：提出现象 → This is because(原因) → This will lead to(后果) → should…(对策)　(Q26)
  3. 总-分-分-收：主题句 → 一方面 → 另一方面(However / also) → The point is…　(Q30 · Q12)
  4. 新闻型：引语金句 + 出处 → 背景 → 细节 / 续引 → 结果数字　(Q8)
  5. 定义 / 规则型：一般规则 → But 特例 → 首例是… → 具体情形 → 兜底　(Q5)
  6. 历史演变型：时间锚(Early in 1938 / By the 1990s) → 怎么做 → 如今 → 评价　(Q1 · Q6)

六、考场 30 秒流程

  1. 快速读完全部句子，圈出每句的：代词 / this+名词 / 连接词 / 数字 / 专有名词
  2. 用"一、排除法"找出唯一首句
  3. 从首句开始，每次只找"勾住上一句"的那句，一环一环往下接
  4. 剩最后一句自然落尾
  5. 交卷前只检查第 1↔2 的接缝：第 2 句里有没有一个词字面指向第 1 句？没有就重排
  6. 通读一遍：代词都有先行词、时间 / 因果都顺 → 提交

七、你的个人易错点（从多张复盘图看出）

头号缺陷（已 4 次）：按"哪句信息最具体、最有画面感"选首句，把平淡的"谁做了什么"框架句埋掉。

  • Q17：把机制句「thin nerves detect pressure」放第一，埋了「壳能感知触碰」
  • Q12：把概括句「people want promotion opportunities」放第一，埋了引入类别的句
  • Q19：把列举句「三个玩具：火车、娃娃、鱼」放第一，埋了「Will 等人做研究…」
  • Q2：把"能源行业缺人"放在"需要工程师"前——先论断、后解释才对

二号缺陷：锁完首句就停止追踪、改回语感——尤其漏 this ＋ 名词 和普通名词前的 the 这类回指（Q9 的 "this effort"、Q17/Q19 的 "the shell / the room"）。

对策：①选首句时，你最想放第一的那句（最有画面感的）几乎一定是第 2–3 句，改挑最平最泛的那句。②见 this / these / such / the ＋ 名词 立刻往前找先行词。③"一般论断 / 概括 → 下一句"，别倒。
